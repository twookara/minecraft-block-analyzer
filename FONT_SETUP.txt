BestTen FONT の配置方法

このZIPにはフォント本体は含まれていません。

次のどちらかで GitHub Pages に配置してください。

方法A（推奨）
/
  index.html
  BestTen-CRT.otf
  manifest.webmanifest
  sw.js
  ...

方法B（元ZIPのフォルダ構成をそのまま使う）
/
  index.html
  Best10-FONT/
    BestTen-CRT.otf
  manifest.webmanifest
  sw.js
  ...

v1.4.1 は両方の配置を自動で探します。

注意:
Best10-FONT.zip を ZIP のまま GitHub に置いてもブラウザは中の OTF を読めません。
必ず BestTen-CRT.otf をファイルとして配置してください。
