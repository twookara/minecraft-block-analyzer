# Minecraft Block Analyzer v1.4.1

## 自動検出
- 1点の強いエッジを四隅として拾う方式を廃止。
- 左右辺は多数の y 行で候補 x を集め、ロバスト直線回帰。
- 上下辺は多数の x 列で候補 y を集め、ロバスト直線回帰。
- 4直線の交点を四隅に採用。
- RMSE、支持点数、基準範囲からの乖離で confidence を算出。
- 72%未満は「要確認」。

## 日本語名・ID
- 日本語入力の予測候補。
- 候補タップで name と正式 minecraft_id を同時入力。
- 一括名前入力でも完全一致ならIDを同時設定。
- 辞書JSONの追加/保存に対応。
- ZIPにも block_name_dictionary.json を同梱。

辞書は将来の本体アプリと共有できるJSON形式です。
